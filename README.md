# altid-mad-site

Marketing site for [Altid Mad](https://altidmad.dk): waitlist, SEO pages and press. Built with Next.js (App Router), deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Tests and production build:

```bash
npm test
npm run build
```

## Deployment

Pushes to `main` deploy to production automatically via the Vercel Git integration. Environment variables are managed in the Vercel dashboard.
